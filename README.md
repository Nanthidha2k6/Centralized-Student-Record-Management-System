# 🎓 Centralized Student Record Management System

A modern, secure, and user-friendly **Student Record Management System** developed using **Spring Boot**, **Thymeleaf**, and **MySQL**. The application simplifies the management of student information by providing a centralized platform for maintaining academic records, attendance, activities, and departmental statistics.

---

## 📖 Project Overview

The **Centralized Student Record Management System** is designed to replace traditional paper-based student record management with a digital solution. It enables educational institutions to efficiently store, update, search, and manage student information through an intuitive web interface.

The system provides quick access to student profiles, attendance records, academic details, and extracurricular activities while reducing manual effort and improving data accuracy.

## ⚙️ Installation

### Step 1
Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/student-record-management.git
```

### Step 2

Open the project using **IntelliJ IDEA**, **Spring Tool Suite (STS)** or **VS Code**.

### Step 3

Configure MySQL database in

```
application.properties
```

Example

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/studentdb
spring.datasource.username=root
spring.datasource.password=your_password
```

### Step 4

Build the project

```bash
mvn clean install
```

### Step 5

Run the application

```bash
mvn spring-boot:run
```

### Step 6

Open your browser

```
http://localhost:8081
```
